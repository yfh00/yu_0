# 贪吃蛇 🐍

一个纯 HTML/CSS/JavaScript 编写的经典贪吃蛇小游戏,无需任何依赖,双击即可运行。

## ✨ 功能特性

- 🎮 **经典玩法**:方向键 / WASD 控制移动
- ⏸️ **暂停/继续**:按空格键
- 🔄 **快速重开**:按 R 键
- 📈 **分数 & 最高分**:最高分自动保存到本地(localStorage)
- ⚡ **动态加速**:每吃 5 个食物提升一档速度
- 📱 **移动端适配**:支持触摸滑动和屏幕方向按钮
- 🎨 **精美界面**:深色主题 + 霓虹光效

## 🚀 如何运行

直接用浏览器打开 `index.html` 即可,或者托管到任意静态页面服务(如 GitHub Pages)。

## 🎯 操作说明

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制方向 |
| `空格` | 开始 / 暂停 |
| `R` | 重新开始 |
